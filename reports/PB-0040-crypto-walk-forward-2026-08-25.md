# PB-0040 加密趋势 walk-forward 增量验证（2026-08-25）

## 方法

新增 `scripts/crypto_tsmom_walk_forward_replay.py`，预注册 8 个候选组合：
`lookback ∈ {60,120}`、`vol_lookback ∈ {20,40}`、阈值 `∈ {0.15,0.25}`。
每个折只用折前数据按域级训练 Sharpe 选择一个候选；OOS 不参与选择，随后每个
标的以新账户通过 `SimulationService` 真实成交内核回放，费用为 20 bps，允许做空。

为了避免训练期成交污染 OOS，内核只接收 OOS 窗口，使用每个标的/折的新初始资本。
权益曲线每 5 个交易日采样一次，成交、费用、账本和最终结算仍逐笔记录；该采样
粒度明确写入结果，不与逐日完整权益证据混淆。

## 最新 OOS 折结果

最新折起点为 `2026-03-11`，18 个主要加密标的，训练选择：
`lookback=60, vol_lookback=40, threshold=0.15`。

| 指标 | 结果 |
|---|---:|
| OOS 平均收益 | -1.85% |
| OOS 中位数收益 | -1.28% |
| OOS 正收益标的 | 8/18（44.4%） |
| 相对买入持有平均超额 | +13.61% |
| 候选族规模 | 8 |
| OOS 盘口深度 | 18 个标的全部 UNKNOWN |

相对基准超额为正并不等于绝对盈利；本轮绝对 OOS 收益为负，因此没有形成可交易
候选，更没有达到年化 50% 或月度 15% 目标。代表性负贡献为 LINK `-27.75%`、
ATOM `-17.36%`、ADA `-10.34%`；正贡献集中在 BCH `+15.40%`、AVAX `+14.56%`、
DOGE `+7.49%`，不足以支撑跨标的推广，且单标的交易数较少。

## 性能与安全

第一次运行发现逐日权益写入和逐笔 INFO 日志导致 CPU 瞬时约 95%，已安全中止，
未纳入结果。随后加入可选事件节拍、采样权益和 OOS-only 执行；重跑期间 CPU 约
16--25%，临时 SQLite 文件保持在 MB 级并在完成后清理。共享内核默认生产行为不变。

## 门禁结论

当前产物 `data/crypto_tsmom_walk_forward_replay.json` 状态为
`replay_only_not_promoted`。仍缺少足够的独立 walk-forward 折、逐月目标、真实
盘口深度/成交链接和多重检验，因此本候选只保留为诊断证据。下一轮应在不改变候选
选择规则的前提下完成剩余折，随后按每个标的补齐月度/年度目标与稳定性门禁。
